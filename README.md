# Switched Mode Power Supply (SMPS) Project ⚡

## Overview
This project presents the design and implementation of a Switched Mode Power Supply (SMPS) used to convert input voltage into a stable DC output with high efficiency.

## Key Features
- **High Efficiency:** Uses high-frequency switching to reduce power losses.
- **Stable Output:** Feedback control elements for voltage regulation.
- **Compact PCB Design:** Optimized layout for noise reduction and thermal management.
